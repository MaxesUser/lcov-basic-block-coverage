# Скриншоты воспроизводимого запуска

Здесь размещаются изображения, полученные на Debian 13 ARM64 после `bash scripts/demo.sh`.
Для защиты рекомендуется сохранить: `cjson-summary.png`, `cjson-source.png`,
`cjson-cfg.png`, `cjson-unknown-blocks.png`, `inih-summary.png`.

Скриншоты намеренно не включены в исходный архив: их следует снять с
реального пользовательского запуска.
