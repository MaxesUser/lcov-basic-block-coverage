# Навигация по результатам анализа

Пошаговый обзор возможностей расширенного отчета. Сначала выполни:

```bash
bash scripts/demo.sh
xdg-open build/cjson/html-extended/index.html
```

1. На сводной странице находятся **Lines**, **Functions**, **Branches** и **Basic Blocks**. Последняя метрика рассчитывается по уникальным инструментированным PC.
2. Перейди в файл `cJSON.c`. Цветные BB-метки расположены у строк, которым сопоставлен PC. **Зеленый** — выполнен, **красный** — не выполнен.
3. Кнопка **Uncovered only** оставляет только метки невыполненных BB. **All blocks** возвращает все метки.
4. Нажми метку и открой **Open function CFG**. Сравни режимы **Simplified** и **Full**, исходы `true` / `false` и начало/конец функции. Ребра здесь возможные, а не измеренные переходы.
5. Открой **Inspect ... blocks without a visible source marker**. Перечень содержит блоки, которым не удалось назначить исходную строку, и не удаляет их из статистики.
6. Сравни `build/cjson/html-original/index.html` с `build/cjson/html-compatible/index.html`: эти варианты проверяются на совпадение стандартных показателей.
7. Повтори обзор в `build/inih/html-extended/index.html`.

Для воспроизводимого запуска на других исходниках см. [USAGE.md](USAGE.md). Для самостоятельного сохранения кадров — [screenshots/README.md](screenshots/README.md).
