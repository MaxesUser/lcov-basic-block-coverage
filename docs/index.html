Report types: Original is generated by the system genhtml; Compatible is generated by the modified genhtml without --bb-report; BB extended adds Basic Block Coverage. The first two have matching coverage data.

Coverage describes the supplied test drivers, not the upstream projects' complete test suites. A gray CFG node represents unknown attribution, not necessarily an unexecuted block. CFG edges describe possible paths.

Source code, reproducibility instructions, and test methodology are available in the corresponding GitHub repository. Pages are an export of the generated reports, not an independent build.
